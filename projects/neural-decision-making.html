About This Project

R Random Forest Feature Engineering Markdown

I analyzed neural activity data from 30,000+ recorded neurons across 18 experimental sessions in R, applying feature engineering and data integration methods to handle imbalanced trial data across 4 experimental subjects. The goal was predicting behavioral outcomes directly from neural activity patterns.

Key Contributions

  • Processed and integrated imbalanced trial data across 4 subjects
  • Engineered features to extract contrast patterns from raw neural recordings
  • Developed a weighted Random Forest classification model
  • Achieved 74.2% accuracy on held-out validation data
  • Identified session progression as a key predictor via feature importance analysis
