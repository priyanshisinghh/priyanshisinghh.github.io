About This Project

R Random Forest Feature Engineering Markdown

This project was built in one of my machine learning focused classes at UC Davis. For this project, I analyzed neural activity data from 30,000+ recorded neurons across 18 experimental sessions in R based on the literature review given. I also conducted feature engineering and applied data integration methods to handle imbalanced trial data across subjects.

The overall goal of this project was predicting behavioral outcomes based on patterns seen in neural activity in mice. To do this, I built a Random Forest machine learning model which scored a 74% on testing accuracy.

Key Contributions

  • Processed and integrated imbalanced data
  • Conducted feature engineering to extract patterns from raw data
  • Developed a weighted Random Forest classification model; achieved 74.2% accuracy on model
