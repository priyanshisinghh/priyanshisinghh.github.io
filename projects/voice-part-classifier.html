Voice Part Classifier

Python, Jupyter · Aug 2025

About This Project

Python Jupyter Audio Feature Extraction Classification

A proof-of-concept ML classification model that predicts vocal part — soprano, alto, tenor, or bass — from audio features including pitch, range, and vocal quality. I built this for a real audition use case within my a cappella group, The Liquid Hotplates, to help speed up initial vocal-part triage during auditions.

Key Contributions

  • Extracted pitch, range, and vocal quality features from raw audio
  • Built a proof-of-concept classification model in Python
  • Designed for a real-world use case, not just a coursework exercise
