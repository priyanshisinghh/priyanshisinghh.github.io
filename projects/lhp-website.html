Website & Brand

The Liquid Hotplates · Sept 2023 – June 2026

About This Project

HTML CSS JavaScript GitHub Pages Canva Figma

As Social Media Chair — and later Publicity + Co-Sunshine/Social Chair — for The Liquid Hotplates, UC Davis's a cappella group, I designed and built the group's website from scratch, and separately managed its Instagram and broader social presence. The site includes a custom glass-card member directory with flip animations, a letter-by-letter animated hero title, a vertical events timeline, and a masonry photo gallery — all built without a framework, deployed via GitHub Pages.

Key Contributions

  • Designed and built the full site in HTML/CSS/JavaScript, including a reusable glass-card component system
  • Built custom animations: letter-by-letter text reveals, 3D flip cards, and a masonry photo gallery
  • Deployed and maintained the site via GitHub Pages across multiple content updates and event cycles
  • Designed and managed Instagram content and club branding using Canva
