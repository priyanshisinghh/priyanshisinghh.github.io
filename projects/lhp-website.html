Website & Brand

The Liquid Hotplates · Sept 2023 - June 2026

About This Project

HTML CSS JavaScript GitHub Pages Canva Figma

As the Publicity (and Co-Sunshine/Social) Chair for The Liquid Hotplates, one of UC Davis's award-winning acappella groups, I designed and built the group's website from scratch, and simultaneously managed the club Instagram and social presence. The website includes many different features such as members, alumni, performance deatils, and photos of the club. I used HTML, CSS, and JS to develop this website and deployed it via GitHub Pages.

Key Contributions

  • Designed and built the full site in HTML/CSS/JavaScript,, including many components
  • Deployed and maintained the site via GitHub Pages across multiple content updates and event cycles
  • Designed and managed Instagram content, social presence, and club branding using Canva
