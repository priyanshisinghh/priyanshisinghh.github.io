ASUCD Pantry

Patron Satisfaction Analysis · Python, Streamlit

About This Project

Python Streamlit Tableau Survey Design

As Data Science Coordinator for the ASUCD Pantry, I designed a patron satisfaction survey and built an end-to-end data pipeline — from collection through cleaning and aggregation — to support a program serving 5,000+ students. The centerpiece is a live Streamlit dashboard that turns raw survey and operations data into insights program coordinators can act on directly, without needing to touch the underlying data themselves.

Key Contributions

  • Designed the patron satisfaction survey instrument from scratch
  • Built the full pipeline: data collection, cleaning, and aggregation in Python
  • Developed the interactive Streamlit dashboard used by program coordinators
  • Presented findings and recommendations directly to non-technical managers
