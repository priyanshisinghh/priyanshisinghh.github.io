About This Project

Python Streamlit Tableau Survey Design End-to-End Project

As a Data Science Coordinator for the ASUCD Pantry, one of my projects was to help my team and interns design a patron satisfaction survey and build an end-to-end data pipeline, including data collection, cleaning, and aggregation. Our findings supported a program serving 5,000+ students.

My team and I built a live Streamlit dashboard that turns the raw survey and operations data into actionable insights and feedback the program coordinators and managers can act on directly to better improve operations.

Key Contributions

  • Led a team of 3+ interns throughout this project
  • Designed the patron satisfaction survey instrument from scratch
  • Built the full pipeline: data collection, cleaning, and aggregation in Python
  • Developed the interactive Streamlit dashboard used by program coordinators
  • Presented findings and recommendations directly to managers to improve operations
